# Lab 05: Basic File Management Operations

## Objective
Practice non-destructive directory creation (`mkdir -pv`), empty file initialization (`touch`), metadata inspection (`ls -lha`), copying (`cp`), renaming/moving (`mv`), and recursive cleanup (`rm -r`) inside an isolated `/tmp` sandbox.

## Execution

```bash
chmod +x file_ops_lab.sh
bash file_ops_lab.sh
